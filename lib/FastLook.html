NAME

FastLook - binary search on contiguous monotonic ranges

VERSION

Version 0.00_00 (unimplemented)

SYNOPSIS

   use FastLook qw(
       bisectl bisectr bixectl bixectr
       blsrch0 brsrch0 blsrch1 brsrch1
       blsrch2 brsrch2 blsrchx brsrchx
   );

   # Input forms (left bisection)
   bisectl { ok($idx = $_) } [\&sub,]$hi; # $lo //= 0
   bisectl { ok($idx = $_) } [\&sub,]$lo, $hi;
   bisectl { ok($elt = $_) } \@list;      # $lo //= $[
   bisectl { ok($elt = $_) } \@list, $lo; # $hi //= $[ + @$list
   bisectl { ok($elt = $_) } \@list, $lo, $hi;

   # Input forms (right bisection)
   bisectr { ok($idx = $_) } [\&sub,]$hi; # $lo //= -1
   bisectr { ok($idx = $_) } [\&sub,]$hi, $lo;
   bisectr { ok($elt = $_) } \@list;      # $hi //= $#$list
   bisectr { ok($elt = $_) } \@list, $hi; # $lo //= $[ - 1
   bisectr { ok($elt = $_) } \@list, $hi, $lo;

   # Output forms (as bi-/tri-section point)
   my $idx               = blsrch0 { ok } \@list;
   my ($idx, $cmp, $elt) = blsrch0 { ok } \@list;

   # Output forms (as dual trisection points)
   my $count       = blsrch2 { ok } \@list;
   my ($beg, $end) = blsrch2 { ok } \@list;

EXAMPLES

Who doesn't love examples!

You can compute the integer square root of $x by searching for the last integer $_ for which holds $_ * $_ < $x holds:

   sub isqrt {
       my ($x) = @_;
       bisectr { $_ * $_ <= $x } $x;
   }
   
   print isqrt(2025), "\n";  # 20+25 :O

DESCRIPTION

Algorithm

There are two classes of binary search algorithm: the left bisection method and right bisection method. Naively, they deal with two classes of monotonic boolean-valued functions, otherwise known as predicates. Namely, call such a predicate ok. Then:

  • Left bisection assumes that the predicate is increasing. That is, if ok(x) is true, then ok(y) is true for all y >= x; and if ok(y) is false, then ok(x) is false for all x >= y. Visually, the image of the predicate looks like: 
       F F F ... F T T T   ok(x)
   1 2 3     6 7 8 9      x

    where there exists a unique point of true's first occurrence.

  • Right bisection assumes that the predicate is decreasing. That is, if ok(x) is false, then ok(y) is false for all y >= x; and if ok(y) is true, then ok(x) is true for all x >= y. Visually, the image of the predicate looks like: 
       T T T ... T F F F   ok(x)
   1 2 3     6 7 8 9      x

    where there exists a unique point of true's last occurrence.

Given the predicate ok and the bounds lo and hi, each algorithm attempts to find that unique point respectively.

To ensure the return value is mathematically consistent at all times, it is assumed that at least one point satisfies the predicate. Namely,

  • Given [$lo, $hi] as its input, the left bisection method assumes that $ok->($hi) to true, and searches on the half-open interval [$lo, $hi) (that is, $ok->($hi) is never actually checked). When it cannot find any truth there, it returns $hi as a last resort. The order passed to the function is what you would expect: 
       bisectl { ok } $lo, $hi

    Commonly for arrays, you would set $hi to the length, which is one past the final index:

       bisectl { ok($list[$_]) } 0, @list

    This checks array elements at index 0 up to @list-1 only, and returns @list as a last resort. You may also omit 0 here as it is the default $lo for left-search functions.

  • Given [$lo, $hi] as its input, the right bisection method assumes that $ok->($lo) to true, and searches on the half-open interval ($lo, $hi]. When it cannot find any truth there, it returns $hi as a last resort. The order passed to the function is reversed: 
       bisectr { ok } $hi, $lo

    This time, you might set $lo to -1, which is one less than the initial index:

       bisectr { ok($list[$_]) } $#list, -1

    This checks array elements at index $#list down to 0 only, and returns -1 as a last resort. You may also omit -1 here as it is the default $lo for right-search functions.

Input forms

The first argument is always a callback, which can be passed using any syntax permitted by the & prototype. Notably, the callback may be given as a block, similar to sort BLOCK and grep BLOCK. The callback receives its argument from $_, the default variable. Its exact value is dependent on the input forms explained below.
